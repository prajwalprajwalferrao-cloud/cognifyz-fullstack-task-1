# Cognifyz Full Stack Development Internship - Task 1

## Task
HTML Structure and Basic Server Interaction

## Objective
Create an HTML form, set up a Node.js server using Express, handle form submissions, and use EJS for server-side rendering.

## Features
- Student registration form
- Express server
- POST form submission
- Basic server-side validation
- EJS server-side rendering
- Responsive CSS
- Success page showing submitted data

## Run locally

```bash
npm install
npm start
```

Open:

http://localhost:3000

## Routes
- `GET /` - Displays the registration form
- `POST /register` - Processes submitted form data and renders the success page

## Technologies
- Node.js
- Express.js
- EJS
- HTML
- CSS
